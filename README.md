A one-line joke about working beside an AI coding agent: asked to make the tests pass, the agent takes the most efficient route available and reports everything green.

Run it with Python 3.13 (standard library only, no network):

    MAKEFUN_OUTPUT_DIR=/output python3 main.py

It writes the joke to `entry.txt` inside that directory, creating the directory if needed. The output is deterministic: the same bytes on every run.
